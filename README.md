# 变异注释归一化平台

面向变异注释数据员的网页工具：把同一变异的不同插缺写法归一到标准 VCF 表示，
按"单条变异作用后的完整序列"判定等价并合并，避免下游重复注释；并可在当前
成功报告上勾选源 ID，把同一样本的多个已确认变异合成一条单倍型 FASTA 供下游比对。

## 功能

- 上传**单条染色体 FASTA**（≤ 4096 碱基）与**变异 CSV**（≤ 20 行，表头含
  `ID,POS,REF,ALT`，POS 从 1 起）。
- 仅接受：**单碱基替换**、**带锚定碱基的纯插入/纯缺失**（VCF 惯例，锚定碱基在事件左侧）。
- 逐行核对 REF 与参考序列；任一非法行 → **整批失败**，不留半份报告。
- 插缺**左对齐**到最左可表示位置（含串联重复中的旋转归一），输出标准 VCF。
- 以"单条变异作用后的完整序列相同"判定等价，**等价行合并**并列出全部源 ID。
- 两份输入可分别**整份更正**；每份报告固定所用输入版本与结果。
- **计算期间更正仍可提交**；旧报告可查但不再是当前结论；迟到完成的结果
  **不能覆盖**更新版本的结论；报告与任务状态单事务写入，失败不留半份。
- **单倍型合成**：在当前成功报告页勾选源 ID，把多个变异按原参考坐标组合成
  一条单倍型 FASTA（详见下文）。

## 单倍型合成

- 在当前成功报告页的"源行 → 标准化对照"表中勾选源 ID，提交后生成一条单倍型；
  **映射到同一标准位点（归并组）的记录只应用一次**。
- 全部编辑**按原参考坐标同时组合**（替换与插缺互不位移）：
  - 共享 VCF 锚点但实际编辑不冲突的事件**可共存**（如插入与缺失同锚点、
    替换与缺失同锚点、替换与插入同位点；首尾相接的缺失同样可共存）；
  - **被删除的碱基不能再被改动**（替换/缺失区间重叠即冲突）**，也不能用作插入锚点**；
  - **不同插入不能占同一断点**。
- 发现冲突**整次拒绝**，失败记录列出全部涉及的源 ID，**不留部分序列**。
- 成功结果保存：所用报告、所选源 ID、完整序列；详情页展示 FASTA 并提供下载。
- 输入更正与生成交错时，旧依据的单倍型**可查但标为"已过期"**，不会标为当前
  （"当前"由依据报告的输入版本是否仍是最新派生）。

## 快速开始

### Docker Compose（推荐）

```bash
docker compose up --build
# 打开 http://localhost:5000
```

数据持久化在命名卷 `appdata`（容器内 `/data/app.db`）。

### 本地运行

```bash
pip install -r requirements.txt
python run.py          # http://localhost:5000
```

### 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `APP_DATABASE` | `instance/app.db`（容器内 `/data/app.db`） | SQLite 路径 |
| `COMPUTE_DELAY_SECONDS` | `2` | 模拟耗时计算的秒数；此期间可提交更正，用于演示/验证并发语义 |
| `SECRET_KEY` | 开发默认值 | 生产部署请覆盖 |
| `PORT` | `5000` | 监听端口 |

## 输入格式

**FASTA**：单个 `>` 标题行 + 序列（可换行，仅 A/C/G/T/N，≤4096 碱基）。

**CSV**：表头含 `ID,POS,REF,ALT`（大小写不敏感、顺序不限），数据 ≤20 行。
ID 唯一且不含空白/逗号/分号；POS 为 ≥1 整数；REF/ALT 仅 A/C/G/T/N。

```
ID,POS,REF,ALT
ins_a,2,T,TT        # 插入：锚定 T 之后插 T
del_x,2,TT,T        # 缺失：删锚定后一个 T
snv_1,6,C,A         # 单碱基替换
```

## 归一化与等价规则

- **左对齐**：插入序列 `S` 在锚定 `p` 处，若 `S[-1] == ref[p]`，则整体左移一位并
  旋转（`S' = ref[p] + S[:-1]`），直至最左可表示位置；缺失同理。
- **等价**：两条变异分别作用于参考序列后得到的**完整序列**相同即等价；
  等价行合并为一组，输出该组左对齐后的标准 VCF 行，`ID` 字段列出全部源 ID
  （`;` 分隔）。

## 版本与并发语义

- FASTA / CSV 各自整份版本化（v1, v2, …）；每次更正自动按最新版本组合排队重算。
- 报告绑定固定的 `(fasta_version, csv_version)`；"当前结论"由版本匹配派生，
  因此迟到完成的旧版本任务**无法**覆盖新结论，只在历史中标记"已过期"。
- 报告 INSERT 与任务状态 UPDATE 同事务提交；非法输入产生的是一份**完整的
  失败报告**（含错误原因、无任何变异行），不存在半份报告。
- 进程重启时被中断的 `running` 任务自动重新排队。

## 测试

```bash
python -m pytest tests/ -q
```

覆盖：左对齐（同聚物/串联重复旋转）、等价归并、逐行 REF 校验、整批失败、
版本更正、迟到结果不覆盖、失败原子性、真实 worker 线程下的计算期间更正；
单倍型：同位点只应用一次、共享锚点共存、被删碱基改动/作插入锚点冲突、
同断点插入冲突、整次拒绝并列出涉及源 ID、失败不留部分序列、
更正交错下旧依据结果可查但不标为当前。

## 项目结构

```
app/
  __init__.py    应用工厂（配置 + 后台 worker 线程）
  normalize.py   纯函数核心：解析/校验/左对齐/等价归并/VCF/单倍型合成
  db.py          SQLite（WAL）连接与建表
  worker.py      任务认领、计算、单事务报告写入
  views.py       路由：建批、更正、批次/报告页、VCF 下载、单倍型合成与下载
  templates/     页面模板
run.py           入口
tests/           pytest 测试
```
